# Million Entertainment PWA

Bienvenue dans le dépôt officiel des fichiers de configuration pour l'application **Million Entertainment**.

## À propos
Million Entertainment est une plateforme dédiée à la promotion de la culture, de la musique et des arts du Grand Kivu, portée par la société **Main Million UNLIMITED**. Cette application est conçue comme une Progressive Web App (PWA) pour offrir une expérience utilisateur fluide et rapide, comparable à une application native.

## Fonctionnalités
* Accès rapide aux contenus du magazine.
* Optimisé pour une navigation mobile.
* Fonctionnalités hors ligne via Service Worker.

## Configuration
Ce dépôt contient les fichiers essentiels pour transformer le portail web en PWA :
* `manifest.json` : Définit le comportement de l'application sur l'appareil de l'utilisateur (icône, nom, écran de démarrage).
